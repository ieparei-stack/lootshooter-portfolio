- 애매하거나 내가 명시하지 않은 것은 절대 추측해서 채우지 마라. AskUserQuestion 도구로 나에게 물어봐라.

8. 작업 방식 (티켓 크기, 커밋 규칙, 확인 방식)

## 원문에 대한 주석

- **파일명 오기**: 원문의 `docs/총기_시큘레이터.html`은 실제로 `docs/총기 시뮬레이터.html`이다(밑줄 아님, "시뮬"). 킥오프 때 확인함.
- **"3정"**: 3단계 인터뷰에서 사용자가 **4정**(CS·PUBG·COD·데스티니형)으로 변경했다. 기준 AR은 사격장에서 제외.
- **"Google Sheets → JSON 변환"**: 데이터 파이프라인 인터뷰에서 **하지 않기로** 최종 결정. 무기 데이터 파일이 곧 소스다.
- **"데이터 파일은 직접 편집 금지(소스에서 변환)"**: 위 결정에 따라 성립하지 않게 되어 CLAUDE.md에서 제외했다.
- **"애매하면 질문"**: 2026-09-03에 **"개발 관련은 묻지 말고 기획만 질문"**으로 범위가 좁혀졌다.
